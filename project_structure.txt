================================================================================
                    CCTV DATA COLLECTION & MANAGEMENT SYSTEM
                           Project Structure Overview
================================================================================

A full-stack geospatial CCTV data collection and management platform.

  Mobile App  : Flutter (Dart) with Riverpod, go_router, flutter_map
  Backend     : FastAPI (Python) with JWT auth, RBAC, Argon2id
  Database    : MongoDB (GeoJSON + 2dsphere indexes)
  Storage     : MinIO / RustFS (S3-compatible object storage)
  Infra       : Docker Compose

================================================================================
WHAT IT DOES
================================================================================

1. GEOSPATIAL CCTV MANAGEMENT
   - Store and query CCTV camera locations on a map (OpenStreetMap)
   - GeoJSON + MongoDB 2dsphere indexes for viewport-based loading
   - Search, filter, paginate, and view camera details

2. ROLE-BASED ACCESS CONTROL (RBAC)
   - Four roles: Administrator, Regional Admin, Supervisor, Viewer
   - Region/township scoping for data isolation
   - Server-side enforcement

3. IMAGE UPLOADS
   - Presigned URLs to MinIO/RustFS for secure, direct-to-storage uploads
   - Images linked to CCTV records

4. JWT AUTHENTICATION
   - Access + refresh token rotation
   - Argon2id password hashing
   - Secure storage on device (flutter_secure_storage)

5. DASHBOARD & STATS
   - Real-time MongoDB aggregations for CCTV counts, status, etc.

6. USER MANAGEMENT
   - Admins can create/edit users with role and region assignment

7. MULTI-PLATFORM
   - Runs on Android, iOS, Windows, macOS, Linux, and Web

================================================================================
KEY FLOWS
================================================================================

LOGIN
  -> JWT issued -> stored securely -> attached to API requests via Dio interceptor

MAP VIEW
  -> viewport-based CCTV loading from API -> markers on flutter_map

ADD/EDIT CCTV
  -> form with map picker -> image upload via presigned URL -> save to MongoDB

TOKEN REFRESH
  - automatic rotation on 401, with retry logic

KEY DEPENDENCIES
================================================================================

FLUTTER (pubspec.yaml):
  - flutter_riverpod     # State management
  - go_router            # Declarative routing
  - dio                  # HTTP client
  - flutter_map + latlong2  # OpenStreetMap
  - geolocator            # Device location
  - image_picker          # Camera/gallery image selection
  - flutter_secure_storage # Encrypted token storage
  - hive                  # Lightweight local DB
  - cached_network_image  # Image caching
  - photo_view            # Image zoom/pan

BACKEND (requirements.txt):
  - fastapi               # Web framework
  - uvicorn               # ASGI server
  - pymongo               # MongoDB driver
  - pydantic              # Data validation
  - python-jose           # JWT handling
  - argon2-cffi           # Argon2id password hashing
  - boto3                 # S3 client (MinIO/RustFS)
  - python-multipart      # File upload handling
